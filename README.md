# Blog Website

A simple full-stack blog website built with Python, Flask, SQLite, HTML, and CSS.

The application allows users to create, read, update, and delete blog posts through a clean web interface.

## Features

* View all blog posts
* Read individual blog posts
* Create new posts
* Edit existing posts
* Delete posts
* Add categories to posts
* SQLite database for persistent storage
* Responsive layout for desktop and mobile screens
* Flask/Jinja2 template system
* Simple and lightweight architecture

## Technologies Used

* **Python**
* **Flask**
* **SQLite**
* **HTML5**
* **CSS3**
* **Jinja2**
